# DaggerML icons — optical pass 01

24 SVGs: eight selected concepts at 16, 20 and 24 px. Choose the matching size rather than scaling a single master. All use currentColor and transparent backgrounds.

Selections: branching-square DAG; square node (N1); outlined play (R1); braces with arrow function; cylinder data; acorn cache; circle-on-line commit (C1); cloud-only remote, vertically recentered after removing the port.

Stroke: 1.5 px at 16/20; 2 px at 24. Square caps and controlled round joins. Geometry adjusted per size. The acorn is intentionally metaphorical (stored for reuse); retain visible labels. Remote can misleadingly suggest cloud-only storage, so label it Remote.

Inline SVG inherits CSS color. For image-element usage, color does not inherit from the host; inline the SVG or explicitly set its color. For labeled buttons, remove role/aria-label and use aria-hidden=true. CLI output should use text labels rather than assuming SVG support.

Review sheet shows light/dark reversal and actual 16/20/24 px specimens at 100% viewing. This is a visual refinement pass, not user comprehension testing or exhaustive browser/DPI testing.
