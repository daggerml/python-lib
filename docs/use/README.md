# Use DaggerML

Use the CLI to create and operate a research project. Use Python to author DAGs and funks within that project.

1. [Get started](../getting-started.md)
2. Learn the [concepts](concepts/README.md)
3. Follow a task-focused [guide](guides/README.md)
4. Consult the exact [reference](reference/README.md)

The [glossary](../glossary.md) defines shared terms. For the product rationale, see [Why DaggerML?](../why-daggerml.md).
